到期与数据说明
本文介绍 Agent 实例到期后的状态变化、数据保留规则及数据保护建议。
到期规则
Agent 实例到期后，不会立即销毁，平台提供
7 天宽限期
。宽限期内续费可完整恢复；超过宽限期未续费，数据将全量销毁，无法找回。
完整时间线
时间节点
实例状态
可执行操作
到期当天
立即关机
无法访问实例、对话历史、文件
到期后第 1–7 天
关机，宽限期中
续费后实例重新开机，数据完整恢复
到期后第 8 天起
全量销毁
数据不可恢复，无任何操作入口
销毁范围
到期第 8 天起，以下数据全部永久删除：
Agent 实例运行环境
全部对话历史记录
文件管理工作区内所有文件
实例内的 Agent 配置与自定义设置
以上数据一旦销毁，无法通过任何方式找回。
宽限期说明
宽限期内实例处于
关机状态
，无法进入实例或查看对话历史。若需恢复使用或找回历史数据，必须在第 8 天前完成续费。续费后实例重新开机，所有数据恢复正常访问。
平台会在实例卡片上显示提醒：
已进入宽限期：红色强提醒 + 倒计时
数据保护建议
提前续费
：建议在到期前完成续费，避免实例关机导致无法访问
定期备份文件
：在「文件管理」页将重要文件下载到本地，不依赖实例存储作为唯一备份
关注到期提醒
：留意实例卡片上的到期警告，在宽限期截止前及时操作
