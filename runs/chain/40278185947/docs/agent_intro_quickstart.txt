快速开始
本文帮助你完成从创建实例到首次与 Agent 对话的完整流程。
前提条件
已注册优云智算账号并完成登录
已准备好支付方式
第 1 步：选择智能体与套餐
进入 Agent 托管的创建页。页面分为「选择智能体」和「选择配置」两部分，右侧为配置确认面板。
选择智能体
：在 Hermes Agent、OpenClaw Agent、DeepSeek Harness 三个智能体中选择一个。它决定实例的默认工作台与执行方式，创建后也可在实例详情中切换。
选择配置
：选择套餐规格。
套餐
配置
价格
适用场景
标准型
2 核 vCPU · 4 GB 内存 · 40 GB 存储
¥69 / 月
日常对话、轻量自动化与单任务执行
进阶型
4 核 vCPU · 8 GB 内存 · 60 GB 存储
¥109 / 月
并行任务、复杂工作流与更高负载
右侧确认面板会同步显示所选智能体、套餐、配置、存储与自动续费状态。确认无误后点击「立即创建」并完成支付。
提示：
自动续费默认开启。如不希望自动续费，可在创建后于实例详情中关闭。
第 2 步：等待实例创建
支付成功后系统自动开通实例，可在实例详情中查看开通状态。完成后实例状态变为「运行中」。
第 3 步：接入模型服务
这是实例开通后要做的第一件事。
未接入模型时，对话、自动任务与通道回复都会失败。
在左侧导航进入「模型服务」，填写四项配置后点击「保存并启用」：
配置名称
：用于区分服务商或用途，最多 40 个字符
API 地址
：模型服务的 base URL，填到
/v1
为止，Agent 会自动补上
/chat/completions
。也可直接点击服务商预设（优云 Coding Plan、智谱 GLM、DeepSeek、通义千问、OpenAI、Anthropic）自动填充
API Key
：在对应服务商控制台新建密钥并复制。提交后会发送到当前实例，前端不保存也不回显明文
模型名称
：按服务商文档中的模型 ID 原样填写，区分大小写
保存后 Gateway 会自动重启，配置立即生效。
提示：
更换模型只改变由谁来推理，不影响已安装的技能、人设和自动任务。但 API Key 不会回显，修改配置时需要重新填写。
第 4 步：完成前置配置
模型接好之后，这几项按需配置，装得越全 Agent 能做的事越多：
安装技能与专家包
：在技能市场中安装所需技能，或切换到「专家包」标签安装成套工作流
注入人设
：从人设库中选一个角色，Agent 的语气与做事风格会随之调整
连接消息通道
：把 Agent 接入 IM 账号，在聊天工具中直接对话
第 5 步：开始对话
在左侧导航点击「对话」，在底部输入框用自然语言描述你的任务并发送。支持多轮连续对话，会话按时间组织并自动保存，点击「新建会话」可以开启新的对话。
后续可做的事
消息通道
：把 Agent 接入 IM 账号，在聊天工具中直接对话
自动任务
：设定定时任务，到点由 Agent 自动执行并推送结果
文件管理
：上传文件供 Agent 处理，下载它产出的文件
升配与续费
：套餐不够用时升级规格
到期与数据说明
：了解到期后的数据保留规则
