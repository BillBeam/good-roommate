# good-roommate（好室友）

> Training personal agents that learn, across many sessions, when to ask, what to remember, and when a memory has gone stale — and measuring whether reinforcement learning teaches them the skill or a shortcut.

## 这是什么

一个模拟用户跨越数月生活的训练环境，加上在里面用强化学习（RL）训练小模型个人 agent 的研究。

核心问题：奖励要隔几次对话才到时，RL 教会 agent 的是"记住、适时问、察觉变化"，还是"反复问、选保守默认"这类捷径？哪些环境设计决定它学到哪一种？

## 一个例子

下面的"周"都是环境里的模拟时间，跑完一遍大约只要几秒到几分钟。

| 模拟时间 | 用户说 | agent 应该做的 |
| --- | --- | --- |
| 第 1 周 | "帮我订周五请同事吃饭的餐厅" | 顺口问一句有没有忌口，记下"花生过敏" |
| 第 6 周 | "最近在练健身，教练让我控制碳水，帮我找个能常吃的午饭" | 察觉记忆里的"爱吃面"已经失效，更新饮食偏好 |
| 第 10 周 | "周末请朋友吃饭，帮我订个地方" | 同时满足"花生过敏"和"控制碳水"，选对餐厅 |

第 10 周的分数由代码对照用户当时的真实状态计算，它取决于第 1 周问没问、第 6 周改没改。agent 看不到用户的真实状态。

两种捷径都能拿高分，但都不是我们要的 agent：

- **每次都重问**：提问几乎不扣分时，每次把所有问题重问一遍，不用记也不用推断。
- **保守默认**：永远订一家不会出错的选项，不用了解用户。
